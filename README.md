# Cerrajero Córdoba — web para GitHub Pages

1. Descomprime el ZIP.
2. Sube **el contenido** a la raíz del repositorio `cerrajeroeurokey/cerrajero-cordoba` (no la carpeta contenedora).
3. Settings → Pages → Deploy from a branch → main → / (root).
4. Publicación prevista: https://cerrajeroeurokey.github.io/cerrajero-cordoba/
5. Envía `sitemap.xml` a Google Search Console una vez publicada.

**Revisar antes de publicar:** confirmar servicios realmente ofrecidos, horarios, cobertura de barrios y localidades, datos legales y política de privacidad. No se afirma atención 24h ni domicilio físico. Las ilustraciones SVG son originales y no fotografías. Las páginas locales deben adaptarse con evidencia propia y contenido específico para evitar contenido repetitivo de bajo valor.
